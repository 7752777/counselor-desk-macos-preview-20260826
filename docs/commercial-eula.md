# Counselor Desk 最终用户许可条款草案

这是产品交付前需要由版权方和专业法律顾问审定的条款草案，不是对客户的最终法律文件。

1. 购买的许可证仅授予订单中指定客户在约定工作区和设备数量内使用对应产品版本的权利，不转移源代码或著作权。
2. 客户不得复制、公开发布、出租、转售激活码或安装包，不得移除版权和许可证提示，不得把产品嵌入其他商业产品。
3. AI 权益只表示客户端 AI 工作流可以使用；客户必须自行提供模型 API Key，并承担模型服务费用、数据合规和输出复核责任。
4. AI 输出只作为建议、草稿或解释，客户仍应依据学校制度和专业判断完成学生工作，不得把系统当作心理、纪律、资助或审批结论的替代品。
5. 许可证服务可以因退款、欺诈、滥用或违反条款撤销授权；撤销不应删除客户已有的本地业务数据。
6. 软件更新不改变客户工作区的业务数据协议。更新前系统创建恢复点，客户仍应保留独立备份。
7. 网页和单文件离线包不提供与 Electron 相同的设备授权安全边界，也不承诺抗逆向 DRM。
8. 具体价格、更新范围、设备数、退款条件、支持期限和适用法律以订单、正式许可协议和售后政策为准。
