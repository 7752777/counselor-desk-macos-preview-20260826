# Counselor Desk 商业服务隐私说明草案

授权服务只处理产品、订单、许可证、设备、支付事件摘要、邮件投递状态和管理员审计元数据。它不接收学生台账、工作留痕、业务附件、模型 API Key、模型输入文本或 AI 完整响应。

- 激活请求只包含许可证 token、工作区绑定标识、设备标识和必要版本信息；服务器使用签名验证和哈希，不把请求写入普通日志。
- 订单访问令牌由服务端密钥派生，数据库只保留哈希。邮件 outbox 的 payload 只包含交付所需的订单和许可证信息。
- 审计记录保存动作、主体类型、主体 ID、时间和错误码；不得记录激活码、完整签名载荷、学生信息或模型凭据。
- 设备列表用于换机和撤销，最多保留许可证绑定范围内的设备元数据。
- 支付平台、邮件服务、云 KMS、数据库托管和更新 CDN 只能接收其完成服务所需的最小字段，具体处理者和保存期限需在正式隐私政策中列明。
- 客户业务数据的本地备份、同步和 AI 出站处理遵循 [v4 隐私与安全边界](./v4-privacy.md)，不因购买许可证而自动上传到授权服务。
