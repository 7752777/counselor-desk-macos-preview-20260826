# Counselor Desk 退款政策草案

这是接入支付平台前的业务草案，正式上线前应由版权方、财务和法律顾问确认。

- 退款申请需要提供订单号和购买邮箱，不应提交学生数据、许可证私钥或模型 API Key。
- 支付平台确认退款后，服务端撤销订单关联许可证并保留最小订单/审计记录；不会删除客户本地学生数据。
- 已激活设备、已下载包、已使用的服务和定制交付可能影响退款判断，具体以订单页面和正式协议为准。
- 支付 webhook 未验真、事件重复或订单状态不一致时暂停自动处理，进入人工核对，不以客户端回调判断退款完成。
- 退款完成后，客户仍可以导出或恢复自己的业务数据，但需要重新购买或获得其他有效许可证才能继续使用受保护的 AI 和更新权益。
