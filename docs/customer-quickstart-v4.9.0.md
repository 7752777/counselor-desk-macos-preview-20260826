# 学工智伴：普通用户购买、激活、更新与互通

这份说明只解决四个问题：在哪里买、买完拿什么、怎么激活、以后怎么更新和换设备。第一次使用请先用工作台里的示例数据，不要直接导入真实学生资料。

## 一、你只需要记住这条流程

```text
选择档位 → 完成支付 → 获得许可证 → 下载应用 → 激活桌面端 → 配对手机/网页端 → 日常备份和更新
```

许可证不是学生数据，也不是 AI 模型 Key。许可证只决定产品档位和更新权益；模型 Key 由你自己配置，模型调用费用不包含在产品价格内。

1. 打开工作台，先使用样例数据体验功能；
2. 打开“购买、激活与服务说明”，选择想购买的档位；
3. 当前购买页为 `https://license.windsky.store/customer`；支付入口尚未接通时不要重复创建订单，也不要导入真实数据；需要人工核验请联系微信 `Windsky0823`。

工作台会记住你选中的档位，并把它带到订单页。用户不会再次从头寻找产品，也不会因为创建订单就被误提示“已经付款”。

## 三、在哪里买、钱到哪里

正式上线后，工作台里的“购买所选档位”按钮只打开受控购买页，并自动带入用户刚才选中的产品。购买页会明确显示商品、金额、支付状态和取件方式。支付平台负责收款和订单状态，独立授权服务负责签发许可证，下载站只负责安装包分发，三者职责分开。

当前受控购买页已经部署，四档产品目录和订单页面可访问；真实微信支付、商户配置、邮件、KMS 和支付 webhook 仍未接通，因此当前页面只能创建待处理订单，不能把它当成已经可以自动收款的正式商城。页面不会伪造“支付成功”。

如果微信支付商户还没有审核完成，试运营可以把链动小铺作为临时收款页。它只承担付款和临时交付，不改变工作台内的档位、激活和授权规则；稳定的正式方案仍是自有购买页接微信支付。没有官方签名回调时，不能让客户端自己判断已付款。

不要把激活码放进公开百度网盘、微信群公告、源码仓库或普通备份。短期人工发码也必须通过受控订单取件页或一对一交付，并保留订单号和发放记录。

## 四、付款后怎么拿到激活码

正式服务有两种交付方式，用户只会看到其中一种：

1. **订单页取件**：付款被支付平台 webhook 或维护者后台确认后，订单状态变为“已完成”，点击“下载许可证文件”。
2. **邮件取件**：付款确认后，系统向下单邮箱发送许可证文件或受保护的取件链接。

收到的 `.cwb-license` 文件或 `CWB-LIC-1.…` 激活码只在本机输入。不要发到群里，也不要上传到网盘。许可证独立签名，最多绑定一个工作区的 3 台设备；换机可以先在设备管理中解绑旧设备。

## 已购买后如何升级 AI

如果已经购买普通版或普通永久更新版，打开同一个“购买、激活与服务说明”，选择更高的 AI 档位，按钮会变成升级流程。工作台把当前许可证交给授权服务验证，服务端按原档位抵扣后计算差价：普通版升级 AI 增强版为 30 元，普通永久更新版升级 AI 增强版为 20 元；永久 AI 档位分别按 50 元和 40 元计算。前瞻体验优惠和赠送资格以人工核验结果为准。

支付完成后，授权服务会生成新的独立许可证并发送到订单邮箱。回到工作台导入新许可证即可解锁 AI；学生数据、工作区和三端配对关系不因升级而删除。客户端不能自己修改差价，也不会把升级当成一次全价新购。

## 五、第一次激活

1. 从交付包中选择 Windows x64/arm64 安装程序，或 macOS Universal ZIP/DMG。当前前瞻包未签名、未公证，系统出现安全提示属于预期；正式商业包必须以签名和公证状态为准。
2. 打开工作台，先选择或创建工作区。
3. 点击灰色 AI 按钮，或者打开“授权、购买与版权”。
4. 粘贴激活码，或导入 `.cwb-license` 文件；二维码是可选的导入方式。
5. 正式签名许可证可以在本地完成签名校验激活；前瞻兑换码和友情 AI 码仍需要联网核验。桌面端会由主进程发送 HTTPS 请求，单文件 HTML 也可以在联网状态下兑换；激活成功后所有 AI 入口会统一刷新，联网后再同步设备状态。
6. 如果买的是 AI 档位，再到 AI 工作台配置自己的模型接口和 API Key。

没有 AI 授权时，AI 按钮仍然可见但会锁定，不会发送请求，也不会保存 AI 结果。只有许可证不等于已经配置模型，两者是两件事。

## 六、桌面端、手机端和网页端怎么互通

推荐把安装了桌面端的办公电脑设为局域网数据中枢：

1. 在桌面端打开“平台联动”，点击“启动局域网数据中枢”。
2. 点击“生成一次性配对码”，桌面端会显示地址、过期时间和证书指纹。
3. 手机或另一台电脑连接同一 Wi-Fi，打开网页端，输入地址或扫描配对二维码。
4. 回到桌面端确认设备名称和配对请求，核对证书指纹后点击“确认配对”。
5. 配对成功后，手机和网页端通过同步接口读取和提交数据；附件使用分块传输和哈希校验。

数据关系很简单：桌面端/局域网主机保存 SQLite、附件和审计，手机和网页端是受控客户端，不直接打开 SQLite 文件。主机离线时，客户端把加密操作放进离线队列，主机恢复后再提交。

不同字段的修改可以自动合并；同一个字段同时被两台设备修改时，进入“冲突收件箱”，由老师选择主机值、客户端值或手工编辑。系统不会用“最后保存的人赢”静默覆盖。

许可证关系也很简单：正式许可证只保存在桌面端的系统安全存储中；手机和网页端通过已配对的工作区令牌使用主机提供的能力，不复制许可证私钥。单独打开的网页或离线 HTML 适合查看和应急处理，不承担与桌面端相同的授权安全边界。

## 七、以后怎么更新，不用卸载

### 桌面端

桌面端打开“版本更新”，点击“检查更新”。系统依次完成：

```text
检查更新权益 → 下载临时包 → 校验清单签名和 SHA-256 → 创建恢复点 → 确认安装并重启
```

更新不会删除学生资料、SQLite、照片、证书、活动附件、工作区目录或局域网配对数据。更新失败会保留旧版本和恢复点，不要先卸载，也不要手动删除数据目录。

普通版和 AI 增强版可以获得当前主版本内的更新；永久更新版可以获得后续核心版本，永久 AI 增强版可以获得后续核心和 AI 版本。安全漏洞和严重数据修复不因更新权益过期而阻断。

### 网页端和单文件离线版

在线网页刷新后使用新版本。单文件 HTML 需要重新下载新文件并打开；浏览器关闭后不能在后台替换本地文件。这是浏览器运行方式的限制，不代表业务数据会自动丢失。使用前先导出恢复包，导入新文件后再恢复工作区。

## 八、换电脑和恢复数据

1. 在旧电脑“平台联动/备份迁移”里执行一次完整备份。
2. 导出恢复包时把 SQLite、附件索引、附件内容和校验信息一起导出。
3. 新电脑安装新版本，先创建空工作区并打开“恢复”。
4. 先看差异预览和容量检查，再确认恢复。
5. 恢复完成后核对学生数量、业务记录数量、附件数量和哈希。
6. 最后重新输入许可证并在设备管理中确认设备数量。

许可证丢失不会导致学生数据丢失；但许可证不能从业务备份中恢复，需要通过正式订单或售后流程重新激活。恢复口令请离线保管，维护者不会提供绕过签名的后门解锁。

## 九、遇到问题先看哪里

| 现象 | 先做什么 |
| --- | --- |
| 购买后没有许可证 | 在订单页刷新状态；确认支付是否真的被平台确认，不要重复付款 |
| AI 仍然灰色 | 检查许可证档位，再检查模型 Key；普通版不会解锁 AI |
| 手机连不上电脑 | 确认同一 Wi-Fi、主机仍在运行、配对码未过期，并重新核对证书指纹 |
| 更新按钮不可用 | 检查更新权益和网络；浏览器/离线版需要手动获取新文件 |
| 数据看起来少了 | 先停止继续编辑，查看数据源、离线队列、冲突收件箱和最近恢复点 |
| 激活码泄露 | 立即联系维护者撤销并重新签发，不要继续在群里转发 |

如果本地 HTML 或旧桌面安装包显示 `LICENSE_SERVICE_UNAVAILABLE`，请重新下载本轮前瞻包，确认能打开授权服务健康地址后再试。前瞻兑换码不是离线许可证；只有正式签名许可证可以在本地完成签名校验。

反馈问题时只提供脱敏描述、复现步骤、版本和错误码，不发送真实姓名、学号、电话、心理材料或业务附件。

## 十、前瞻和贡献者兑换码

维护者可能向前瞻体验用户或被采纳建议的贡献者私下发放 `CWB-REDEEM-1...` 兑换码。打开“商业授权”，粘贴兑换码并联网点击激活即可；系统会把当前工作区兑换成独立许可证，而不是让所有人共用同一张授权。

- 前瞻兑换码：兑换“普通永久更新版”，完整基础功能可用，AI 仍保持锁定。
- 贡献者/老客户兑换码：兑换“永久 AI 增强版”，AI 入口解锁；仍需自行配置模型 API Key 并承担模型调用费用。

如果收到单独的友情 AI 码，必须先完成 AI 许可证激活，再在同一个商业授权窗口输入友情码。它不会重新签发许可证，而是为当前工作区建立开发者托管 AI 资格；成功后工作台自动选择托管服务。托管 Key 不会下发到本机，服务由开发者自费提供，可能受上游波动和每日额度影响。

同一个工作区重复输入同一兑换码不会重复签发。输入 AI 码会直接覆盖普通前瞻授权的功能边界，不需要先卸载或删除工作区。兑换码只应由维护者私下提供，不能转发到群、截图、业务备份或公开文档；如发现泄露，请联系 `Windsky0823` 暂停活动或处理已签发许可证。
