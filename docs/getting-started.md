# 开始使用

辅导员工作台提供网页体验、离线网页和桌面端三类入口。它们的目标相同：把数据保留在使用者掌握的设备上；但浏览器与桌面端的数据位置、容量、权限和备份方式不同。

## 选择前先判断

| 使用方式 | 适合的情况 | 需要留意 |
| --- | --- | --- |
| 在线体验 | 想试用界面与流程 | GitHub 仓库已私有，原 Pages 当前返回 404；请使用获授权的历史离线包或本地构建，只使用演示或脱敏数据。 |
| 离线 HTML | 无法安装软件、临时演示、希望单文件携带 | 浏览器可能限制本地存储；重要数据必须另存备份。 |
| Windows / macOS 桌面版 | 固定电脑长期整理资料和附件 | 使用 Release 的实际安装包；升级前备份，按学校制度保管数据目录。 |

> **正在阅读仓库页面？** 当前维护版本为 v4.8.5。正式资料建议在受控设备使用有权限访问的 [v4.8.5 Release](https://github.com/7752777/counselor-desk/releases/tag/v4.8.5) 离线 HTML 或桌面端，并以 Release 实际附件、版本号与 SHA-256 清单判断可下载版本；v4.8.3、v4.8.2、v4.8.1、v4.8.0 及更早版本作为历史兼容版本保留。

版本和功能的当前发布状态、已知限制与后续维护，请以[当前全量状态与后续提升路线](./upgrade/comprehensive-status-and-roadmap-2026-08-22.md)和[v4.8.5 发布收尾记录](./upgrade/release-v4.8.5.md)为准；历史过程对账见[全量开发计划对账](./upgrade/full-plan-reconciliation-2026-08-19.md)。

## 下载与核对

1. 打开 [Releases](https://github.com/7752777/counselor-desk/releases)。
2. 选择明确标注的正式版本，不下载 Preview、草稿或未说明用途的附件。
3. 阅读 Release 说明中的平台、哈希、签名/公证状态与已知限制。
4. 核验完成后再安装或打开。未签名包只能在确认来自项目 Release 后自行决定是否继续。

## 数据安全的第一原则

本地优先不是“数据自动安全”。真实学生资料应至少满足：受控设备、受控系统账户、合规的备份介质、最小范围的共享，以及符合本校制度的保管期限。工作台不替代学校的正式系统和审批流程。

## 第一次使用的推荐顺序

1. 先打开设置，留下喜欢的称呼、所属学院和主题色；每日问候可在设置中重新开启或关闭。
2. 用 5 至 10 条虚构或脱敏学生数据完成一次导入预览，不要把唯一一份正式名单作为第一次测试。
3. 选择一名演示学生，补一条谈话或待办，确认学生档案、时间线和提醒能串起来。
4. 建立恢复点，导出一份备份；在另一浏览器配置或测试环境试一次恢复。
5. 确认本校字段、材料和数据保管要求后，再逐步导入正式台账。

6. 在模板中心下载需要的 CSV/XLSX 模板；模板第一行同时给出中文表头和稳定字段名，第二行是示例数据。正式导入前先用脱敏样表核对导师、班主任、家长、居住、通讯录和课表字段。

7. 如果需要照片或查课查寝附件，先在“本地容量”页确认剩余空间，再用一条脱敏记录验证上传、备份和恢复。

完成这七步后，再阅读 [用户手册](./user-guide.md) 按场景展开使用；遇到换机、交接或恢复，直接进入 [备份与迁移](./v4-migration-and-backup.md)。
