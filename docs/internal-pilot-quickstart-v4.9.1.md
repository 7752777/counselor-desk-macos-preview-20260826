# 学工智伴 v4.9.1 前瞻版体验说明

这是给前瞻体验计划参与者使用的免费体验包。前瞻版不需要付款或激活码；如果体验的是商业候选桌面包，维护者也可能单独提供基础码、AI 码或友情 AI 码。前瞻版用于体验业务功能、界面、样例数据、导入导出、备份和反馈流程，不代表正式商业安装包。

## 开始使用

1. 解压收到的前瞻版交付包。
2. 优先双击 `学工智伴-v4.9.1-前瞻版体验版.html`。
3. 首次打开先使用样例数据，依次体验工作台、学生台账、谈心谈话、工作留痕、成绩、住宿、备份恢复和 AI 工作台。
4. 只使用虚构数据测试，不要导入真实学生姓名、学号、电话、心理材料或附件。

Windows 用户也可以安装同包内的桌面安装程序。桌面版更适合体验附件、SQLite、本地备份和局域网协同；安装程序是前瞻版未签名包，Windows 可能显示安全提示。

## AI 测试

普通前瞻版体验包不要求商业激活；商业候选包若收到 `CWB-REDEEM-1...`，可在灰色 AI 入口中粘贴并联网激活。普通活动码不解锁 AI，AI 活动码只解锁产品 AI 权益，仍需要体验者自己配置兼容的模型服务和 API Key，模型费用由体验者自行承担。不要把任何 API Key 或兑换码发给开发者或放进反馈截图。

如果暂时没有模型 Key，可以先体验 AI 页面、上下文选择、提示和人工确认流程；没有模型连接时不会生成真实结果。收到友情 AI 码的贡献者，必须先激活 AI 许可证，再在商业授权窗口的“友情 AI 服务”区域输入友情码；服务由开发者自费提供，受上游波动和每日额度限制，不要把友情码发到群里。

请把问题、复现步骤、页面名称、版本号和错误提示发给开发者微信 `Windsky0823`。反馈中不要包含真实学生资料、激活码、API Key 或敏感附件。

被采纳的有效功能建议，后续按前瞻体验规则核验并赠送永久 AI 增强版授权。

- 前瞻版体验包的数据默认保存在使用者自己的浏览器或电脑中，不会自动上传给开发者。

- 当前前瞻版用于功能体验；正式商业授权、在线支付、自动更新和签名安装包将在生产配置完成后另行发布。
