## 1. 先认识工作台

学工智伴是一套本地优先的高校学生工作空间。它把学生台账、谈心谈话、任务、工作留痕、成绩帮扶、班团组织、党员和团员发展、住宿、查课查寝、奖惩、活动、资料、就业、科研和导入导出放在同一条工作脉络里。

它解决的不是“再做一个表格”，而是让一次已经发生的工作可以继续被找到：

- 名单导入后，学生身份、历史学号和业务记录仍然保持关联。
- 谈话、家长联系、任务、查课、查寝和活动完成后，可以生成待确认工作记录草稿。
- 成绩、获奖、旷课、住宿、重点关注和班委履职可以按班级、学期和时间范围分析。
- 照片、证书和活动材料进入附件仓，业务记录只保存附件 ID。
- 换机、交接、升级和误操作前都有备份、恢复点、差异预览或回滚路径。

工作台帮助老师整理事实、安排跟进、准备材料和复盘工作，但不替代学校学工系统、心理专业评估、正式审批、纪律处分认定或危机处置流程。

## 2. 三分钟体验路径

### 第一步：先用样例数据

第一次打开时，欢迎页建议先浏览脱敏样例数据。样例学生、任务和记录带有演示标记，只用于阅读功能和练习按钮，不会替代正式工作区数据。可以从首页依次打开今日工作台、学生台账、谈心谈话、成绩分析和备份页面。

### 第二步：完成一条完整工作链

建议使用下面这条短路径熟悉产品：

1. 在学生台账查看一名样例学生的档案和时间线。
2. 新建一条谈话或家长联系记录，填写结果和下一步。
3. 点击生成工作记录草稿，检查来源和内容，先不要直接当作事实归档。
4. 在任务页确认回访任务，回到首页查看今日摘要。
5. 在备份页生成一次恢复点，并打开差异或完整性检查结果。
6. 打开设置中的“授权、购买与版权”，查看 AI 锁定、档位和更新说明。

这条路径故意把“录入”和“长期维护”分开：开学时先录基本信息，期中或期末再补成绩、请假、住宿、奖助勤和材料。系统通过稳定的 `student_id`、当前学号和历史学号继续定位同一个学生，不要求一次把所有字段填完。

### 公众号体验入口

公众号名称为“学工智伴”。菜单中的“产品能力”适合先了解范围，“使用指南”适合第一次上手，“前瞻版”用于获取体验说明。也可以在公众号中回复“功能”“体验”或“反馈”。公众号文章只用于产品介绍和问题收集，不接收学生名单、照片、心理材料、密码或模型 API Key。

### 第三步：再导入正式数据

正式导入前准备一份脱敏副本，确认字段映射、学生数量、重复项、未匹配项和敏感字段范围。首次接入真实数据前先建立备份，完成后抽查学生、成绩、住宿和附件关联。

## 3. 界面与阅读方式

工作台使用稳定的三段式桌面结构：

```text
左侧导航        中央主工作区                    右侧上下文区
模块与常用入口  统计、筛选、主操作、结果列表    当前学生、待办、AI 与快捷动作
```

- 1280px 及以上显示右侧上下文区，适合同时看学生和当前工作。
- 1024px 至 1279px 默认收起右侧区，可按需打开。
- 900px 以下恢复导航抽屉、单列主区和底部快捷操作，不强行压缩三栏。
- 页面通常按“标题和主操作、统计摘要、筛选、结果列表”顺序阅读。
- 主按钮只承担一个明确动作，导入、导出、模板、删除和取消使用次级层级。
- 页面正文约 14 至 15px，行高约 1.6 至 1.7；表格正文约 13px，便于长时间阅读。

桌面卡片、表格和照片名册是同一份数据的不同阅读方式。手机端优先保证筛选、编辑、保存和返回可操作；表格在自己的区域滚动，不把整个页面撑出横向滚动。

## 4. 今日工作台

首页的核心问题是“今天先做什么”。顶部工作摘要只放最重要的 4 至 6 个数字：未完成任务、今日到期、逾期事项、待回访、待确认工作记录和待处理导入/附件事项。

待办采用“摘要条 + 可展开清单”：默认只显示最紧急的 5 项，按逾期、今日、近期和待确认分组；点击“查看全部”进入对应模块，而不是把所有记录铺成长页面。折叠状态会保存在当前工作区，移动端使用两行紧凑布局。

首页还可以显示今日课程、最近谈话、重点学生提醒、备份状态、局域网同步状态、离线队列和冲突数量。首页不读取全部照片和附件原文，图片和图表按需加载。

## 5. 学生台账

学生台账是所有学生业务的入口。支持表格、卡片和照片名册三种模式，适合分别处理大批量核对、日常浏览和快速识别。

### 查询和批量处理

- 按姓名、当前学号、历史学号、班级、年级、性别、学生类型、住宿状态、导师、班主任、关注类型、危机等级和预警状态筛选。
- 保存常用筛选、列顺序、列宽、每页条数和显示模式。
- 支持当前页选择和全选筛选结果；批量操作前展示影响数量和字段差异。
- 批量编辑班级、导师、班主任、家长字段、住宿类型和自定义字段。
- 批量归档或删除需要确认，并保留恢复点和审计；失败时保留表单和重试入口。

![学生台账卡片：照片、住宿和负责教师一屏查看](../assets/screenshots/v4.9.0/05-students-cards.png)

![学生照片名册：快速识别、补采和批量整理](../assets/screenshots/v4.9.0/06-students-photos.png)

### 学生导入原则

导入默认是“合并更新”：来源表缺少某个学生不会导致旧记录被删除；文件只出现的字段才更新，空白默认保留原值。需要清空字段时必须显式选择清空空值。

身份匹配优先级为 `student_id`、当前学号、历史学号、人工核对。姓名永远不自动匹配，同名或多个候选会进入核对清单。更正学号只更新快照并追加历史学号，不创建新的学生业务主体。

覆盖导入只有在明确确认源文件是完整名单后才能执行，并在写入前显示删除数量和恢复点。导入模板会说明字段类型、日期格式、敏感标记和清空规则。

## 6. 学生档案与时间线

档案编辑页覆盖常用 schema 字段：照片、姓名、学号、历史学号、性别、出生信息、班级、年级、专业、培养层次、政治面貌、学生类型、导师、班主任、家长关系、家长电话、邮箱、QQ、紧急联系人、家庭地址、居住类型、房东电话、宿舍快照、退伍士兵身份、奖助勤分类、伙食补助和困难认定材料。

所有关联优先使用稳定 `student_id`。学号只是当前快照和兼容索引，不能作为替代主键。学生卡片默认显示照片、班级、宿舍、导师、班主任和家长关系；家长电话默认脱敏，查看完整号码需要访问锁确认并记录审计。

统一时间线把谈话、家校联系、成绩、预警、帮扶、住宿变动、奖惩、活动、工作留痕、党团发展和班委任职放在一个可回看的上下文中。时间线显示来源状态；来源被修改或删除时，不把旧草稿自动当作最新事实。

## 7. 谈心谈话、家校联系与工作留痕

### 谈心谈话

新建谈话时填写学生、日期、方式、主题、摘要、判断、下一步、附件、危机等级和回访日期。会前 briefing 只提供当前档案、近期记录、待办和需要核对的事项；它是工作提示，不是心理诊断。

保存后可以生成一个待确认工作记录草稿。草稿显示来源记录、对象、日期、结果、后续动作和来源变化状态。老师可以编辑、合并、驳回或确认；确认前不会写入正式工作留痕。同一业务记录只能保留一个有效草稿。

### 家校联系

家长联系单独保存在家校联系记录中，不把一次沟通埋在学生基础字段里。记录包含家长关系快照、联系日期、方式、目的、沟通摘要、结果、下一步和附件。保存后同样可以生成待确认草稿。

### 正式留痕

任务完成、查课、查寝、活动或班会完成、通知转化等动作都可以进入同一套草稿链。确认后才写入正式留痕，导出时保留来源集合、来源记录 ID、来源标题和来源状态，方便复核。

## 8. 任务、通知与日程

任务支持逾期、今日、近期和待确认分组，可关联学生、班级、课程、科研课题、住宿批次、通知或来源记录。完成任务时不直接生成“已经发生”的工作事实，而是根据来源创建待确认草稿。

通知页面采用原文输入和 AI 结果双栏：老师主动粘贴通知或导入文本，系统提取标题、来源、接收时间、适用对象、重点、截止时间、待办、需要核验的信息和原文证据片段。结果可编辑、重新生成、复制、保存草稿，并分别转为任务或工作留痕。

系统不读取钉钉、学校后台或浏览器通知，不在后台代替老师接收外部信息。通知原文默认只保存摘要和哈希；完整原文只有用户明确选择保存时才进入本地资料库。

## 9. 课表、查课与随机点名

课表支持导入、周视图、列表视图和打印，默认只覆盖辅导员带班班级。查课页面展示今日课程、正在上课、未查课程、未到和迟到数量以及异常统计。

查课先记录事实，再维护处理措施；查课照片和附件进入附件仓。随机点名支持多班级、单人或多人、不重复抽取、随机种子、结果复核和大屏准备状态。随机数由本地随机源决定，AI 不参与抽取。

点名结束后可保存结果，按需要生成工作记录草稿。缺失考勤不直接当作旷课；请假、未记录、旷课和迟到分开统计。

## 10. 住宿专项与查寝

住宿专项和校外住宿分开。楼栋管理包括校区、名称、性别限制、启用状态和备注；房间管理包括楼栋、楼层、房间号、床位数、床位编号和状态；批次记录学年、学期、批次类型和说明。

### 排宿和调宿

排宿方案先生成预览，逐项检查容量、性别限制、重复入住、床位冲突和未分配学生。只有人工确认后才更新学生当前楼栋、房间和床位快照。调宿记录原位置、新位置、原因、日期、操作人和附件，不覆盖历史住宿轨迹。

### 查寝和异常

查寝记录检查日期、批次、楼栋、房间、检查人、结果和照片/附件。异常单独记录类别、等级、描述、处理期限、状态、处理结果和关闭时间。住宿统计可以按楼栋、楼层、房间、月份和未处理异常筛选。

## 11. 班团组织与发展流程

### 班委

班委角色字典保存在当前工作区，默认包含班长、团支书、学习委员、生活委员、心理委员等，也可以增加权益委员、就业委员、科研委员、宣传委员和文体委员等自定义角色。支持一人多职、代理任职、空缺、继任和任期。

班委考核按周期和日期录入，等级为优秀、良好、合格和不合格，可填写备注和改进建议。AI 只能提供评价草稿，不能自动保存最终等级。

### 党员和团员发展

党员流程以统一主记录保存阶段、日期、规则版本、来源 URL、核验时间、节点状态和审计；空日期保持为空，不显示为今天。团员发展采用国家基线加学校附加节点，核心节点不可删除，学校只能增加材料、审批和提醒节点。

系统只做流程提醒和材料完整性检查，不生成资格认定、审批结论或组织判断。正式节点和校内规则以学校党团组织要求为准。

## 12. 成绩、预警与班级分析

成绩支持按学期和课程导入、趋势查看、挂科分布、GPA、班级均值、学期对比和学生下钻。请假与课表时间段相交后可以计算覆盖课时，但已批准请假、未记录考勤、旷课和迟到分开显示。

班级分析支持班级、年级、学期和时间范围筛选，汇总学生人数、获奖、处分、旷课/迟到、谈话、重点关注、学业预警、资助、活动、班委履职和就业状态。缺失记录显示“未记录”，不能直接当作零。

## 14. 就业、科研、竞赛与实用工具

### 就业和竞赛

## 15. AI 工作区

AI 不是独立聊天窗口，而是嵌入具体工作动作：

| 场景 | AI 可做什么 | 人工确认边界 |
| --- | --- | --- |
| 学生档案 | 摘要、资料缺失提醒、成绩趋势解释 | 不修改学生事实，不下心理或危机结论 |
| 谈话与家校 | 会前 briefing、谈话整理、回访建议 | 只保存草稿，老师确认后才归档 |
| 通知与任务 | 重点提取、截止时间、任务和留痕草稿 | 不后台读取通知，不自动制造事实 |
| 班级分析 | 聚合报告和指标解释 | 敏感指标阈值保护，不能把缺失当零 |
| 住宿/查课/查寝 | 冲突解释、材料缺失和批次摘要 | 不自动分床位、不确认考勤和异常结论 |
| 证书和表单 | 字段识别、映射建议、缺失检查 | 人工确认学生、证书和字段后写入 |
| 心理语音 | 单次授权后的转写和整理草稿 | 默认不保存音频，不生成诊断或危机结论 |
| 政策、就业、科研 | 摘要、适用对象、材料清单和提醒 | 保留来源和证据，老师核对原文 |

未激活 AI 权益时，按钮仍可见但保持灰色锁定，带锁图标、`disabled`、`aria-disabled` 和激活入口。业务函数和请求发送前还会再次检查，不能只靠 UI 样式限制。

有 AI 权益但未配置模型 Key 时，系统提示配置模型。模型 Key 和产品许可证完全分离，模型调用费用不包含在四档价格中。默认脱敏、逐次敏感授权、调用审计、来源引用和人工确认继续有效。

## 16. 导入、导出、备份与跨端

### 导入导出

支持 CSV、XLSX、DOCX、PDF、打印 HTML、模板说明、错误行定位、字段映射、敏感字段预览和附件索引。导入支持暂停、取消、重试、冲突处理、进度和失败回滚。

### 备份恢复

浏览器使用 IndexedDB 保留本地加密快照；Electron 使用 SQLite、附件仓和独立恢复点。备份前进行容量和完整性检查，恢复先做差异预览，再创建当前工作区回退快照；失败自动回滚，不覆盖当前有效数据。

许可证状态、设备令牌和模型 API Key不进入业务备份、学生导出或手机交换包。许可证丢失不影响学生数据恢复，但恢复后需要重新在线激活授权。

### 局域网和便携交换

局域网主机负责事务、版本、附件和审计，客户端通过 HTTPS、证书指纹和配对令牌连接；不同字段可自动合并，同字段冲突进入人工收件箱。主机离线时客户端保存加密离线队列，恢复后再提交。

浏览器关闭期间不能后台写文件或同步；网页和单文件离线包也不承担与 Electron 相同的授权安全边界。正式使用前请确认数据源、最近备份、离线队列和冲突数量。

### 桌面端、网页版和单文件离线 HTML 怎么选

| 形态 | 适合做什么 | 数据位置 | 授权与更新边界 |
| --- | --- | --- | --- |
| Windows Electron 桌面端 | 正式长期使用、备份、附件、局域网主机和无卸载更新 | 本机 SQLite、附件仓和独立恢复目录 | 正式商业载体；授权状态放系统安全存储；支持签名清单更新 |
| 在线网页版 | 临时访问、同一局域网配对后的手机/浏览器客户端 | 浏览器 IndexedDB，或通过局域网主机读取工作区 | 配对后使用主机工作区能力；网页本身不复制许可证私钥；刷新获取在线版本 |
| 单文件离线 HTML | 无网络演示、应急查看、前瞻版体验 | 当前浏览器 IndexedDB | 受限伴侣；关闭浏览器后不能后台更新文件；获取新 HTML 后再导入恢复包 |

三端不是三份自动互相覆盖的数据库。需要共享同一份正式数据时，由桌面端启动局域网数据中枢，手机和网页版通过一次性配对码加入；单独打开的网页或离线 HTML 只代表自己的本地工作区。一次购买的许可证绑定工作区并最多允许 3 台设备，配对客户端不需要复制许可证私钥；没有配对时，不能把三个端的本地数据假定为已经同步。

### 换机时怎样把学生资料和附件一起带走

先在旧桌面端生成完整恢复包，包内包含 SQLite、附件索引、附件内容、校验信息和迁移记录，不包含许可证、设备令牌或模型 API Key。新电脑安装新版后先打开恢复向导，检查学生数量、记录数量、附件数量和哈希，再确认恢复。恢复成功后重新激活许可证并重新配对手机；不要直接复制正在使用的 SQLite 文件，也不要把许可证放进业务备份。

## 18. 无卸载更新

Electron 更新流程为“检查 -> 下载临时包 -> 校验清单签名、SHA-256 和平台签名 -> 创建恢复点 -> 用户确认 -> 重启安装 -> 健康检查”。更新不删除 SQLite、附件仓或工作区数据目录，不需要先卸载旧版本。

Windows 安装器支持自定义程序目录，数据目录与程序目录分离。macOS 商业发布需要 Developer ID 签名和公证。当前候选代码有校验和回滚契约，但真实平台证书、更新 CDN、跨重启安装和公证仍需外部证据。

浏览器在线版本通过刷新获取新版本；单文件离线 HTML 不承诺后台自动更新，只能检查版本并下载新的离线文件。更新失败时不要卸载或手动删除数据目录，保留失败目录、恢复点和 `vault/update-install-state.json` 交给维护者处理。

## 19. 隐私、安全与责任边界

- 默认本地优先，业务数据不因使用 AI 自动上传。
- AI 出站前执行脱敏；敏感内容需要每次明确授权，授权只对当前请求和范围有效。
- 照片、证书、活动和查寝附件只进入附件仓，业务记录保存附件 ID。
- 许可证私钥、模型 Key、设备令牌、订单取件令牌不进入源码、普通日志、业务备份、手机交换包和学生导出。
- “重点学生锁”只防误看，不等同数据库级加密；真正的数据库加密需要单独安全项目。
- 心理、危机、资助、纪律、预警和奖惩信息遵循学校制度、最小权限和访问审计。
- 任何 AI 结论都不能替代辅导员、党团组织、心理专业人员或学校正式审批判断。

## 20. 常见问题

### 没有购买 AI 档位，能看到 AI 按钮吗？

能看到入口，但按钮会保持灰色锁定，点击只进入授权说明和激活页面，不会发送请求，也不会保存 AI 结果。

### 买了 AI 档位，为什么还要配置模型 Key？

许可证只证明产品 AI 权益，不包含第三方模型账号或调用费用。模型 Key由使用者自己配置和承担，系统不会把它写入业务备份。

### 正式客户能不能所有人共用一个 Key？

正式客户不采用共享许可证。每个订单签发独立许可证，按工作区和设备管理，便于换机、撤销、售后和审计。只有受控前瞻体验活动才允许多个工作区输入同一个长期兑换码；兑换后仍是独立许可证。

### 能不能把激活码放百度网盘公开分享？

不能。激活码是高敏授权凭据，应该通过受保护订单取件页或受控人工交付提供，不放公开网盘、群聊、源码仓库或普通备份。

### 更新是不是必须卸载重装？

Electron 正式流程支持无卸载更新，数据目录保持不变。网页和离线 HTML 需要手动获取新文件，这是浏览器运行方式的限制。

### 手机和桌面端是不是要分别购买、分别激活？

同一局域网工作区由桌面端承载时，不需要为手机和网页版重复购买；它们通过配对令牌使用主机提供的工作区。许可证只在桌面端安全存储中保留，手机和网页版不保存许可证私钥。单独打开的网页或离线 HTML 是独立本地工作区，不能自动读取桌面端数据；正式长期使用应先配对主机或使用恢复包迁移。

### 我在开学时只录了基本信息，期末怎样补成绩？

在导入预览中选择“合并更新”，用学号或稳定身份匹配，只上传实际变化的成绩字段。姓名不会单独触发自动合并；重复学号、同名候选和学号变更会进入人工核对。确认前查看逐字段差异，保存成功后抽查学生档案和成绩分析。

### macOS 版本现在可以直接交付吗？

当前前瞻交付包已经包含 macOS Universal DMG/ZIP，远端构建完成了 `.app` 存在性、Intel/Apple Silicon 双架构和 Bundle ID 校验。它仍是未签名、未公证的诊断包，只适合前瞻体验；正式商业发布还必须使用 Developer ID 签名、公证并完成 Mac 实机安装升级验收。

### 浏览器关闭后还会自动备份吗？

浏览器关闭期间不能后台写文件。Electron 或局域网主机运行时可以按计划备份；浏览器端要使用用户选择的目录和页面仍在运行时的备份能力。

### 许可证丢了，学生数据会丢吗？

不会。许可证与业务数据分开保存；恢复业务备份后，需要重新在线激活许可证，不能从业务备份恢复授权，也没有绕过签名的后门。
