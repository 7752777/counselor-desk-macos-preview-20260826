# 三分钟快速上手

这页写给第一次打开辅导员工作台的老师。你不需要安装 Node.js、Git 或其他开发工具。

## 1. 选择一种使用方式

| 你的情况 | 建议 | 说明 |
| --- | --- | --- |
| 想先看看界面 | 获授权的历史离线包或本地构建 | GitHub 仓库已私有，原 Pages 当前返回 404；正式数据只在受控设备使用。 |
| 不想安装，临时或离线使用 | 网页离线版 | 从 [Release](https://github.com/7752777/counselor-desk/releases) 下载实际存在的 HTML 文件，双击打开。 |
| 在固定 Windows 电脑上长期使用 | Windows 桌面版 | 从 Release 下载实际存在的 Windows 安装包；安装、升级和数据位置见[桌面端安装](./v4-desktop-installation.md)。 |
| 在 Mac 上使用 | macOS 桌面版 | 只使用 Release 中实际存在且说明完整的 DMG/ZIP；签名和公证状态以 Release 为准。 |

> 不要从仓库源码、开发分支或截图推断“已经发布”。当前正式版本是 `v4.8.5`，请从私有仓库的 [v4.8.5 Release](https://github.com/7752777/counselor-desk/releases/tag/v4.8.5) 下载实际附件；下载文件名、版本号、哈希和签名状态均以 Release 页为准。`codex/ai-upgrade` 只用于维护，不替代正式 Release。

完整的历史发布、当前 v4.8.5 能力、AI 边界和后续维护见[当前全量状态与后续提升路线](./upgrade/comprehensive-status-and-roadmap-2026-08-22.md)；历史过程对账仍见[全量开发计划对账](./upgrade/full-plan-reconciliation-2026-08-19.md)。

## 2. 第一次打开，先做四件小事

1. **设置工作偏好**：填写自己喜欢的称呼，选一套舒服的主题。每日问候可在设置中随时关闭或重新打开。
2. **先用脱敏样表熟悉导入**：到学生台账打开导入入口，先看“字段映射”和“预览结果”。确认姓名、学号、班级等列对齐后再写入。
3. **建立第一份备份**：打开“备份与迁移”，导出一份备份并保存在受控位置。不要把备份随手发到群聊或公共网盘。
4. **从一个真实工作入口开始**：可以先维护学生台账，也可以先记录一条谈话、建立一项待办或归档一份政策材料。

## 3. 一条推荐的练习路径

1. 导入 5–10 条**虚构或脱敏**学生数据。
2. 用姓名、班级或关注类型筛选一位学生，打开档案。
3. 新建一条谈心谈话或待办，写下下一次跟进时间。
4. 在资料库归档一份不含个人信息的模板。
5. 导出备份，再在测试环境中尝试恢复。

做到这里，你已经走完了工作台最重要的闭环：**数据进得来、事情记得下、线索找得到、重要时刻带得走。**

## 4. 接下来最常见的三个动作

### 给一个班建立可反复使用的台账

先导入班级名单，再补充社区/书院、培养层次、学生状态、关注类型等本校常用字段。用“保存筛选”留住高频组合，用个人列视图把眼前真正需要的信息放在前面。名单较大时，使用 10 / 20 / 50 / 100 条分页，而不是一次把所有记录塞进浏览器。

### 把一次谈话接到下一次跟进

谈话后记录时间、主题、事实性要点、下一步和回访日期。需要附件时，先确认文件中没有不必要的敏感信息。后续在学生档案时间线中回看，不要只依赖某一个 Excel 文件名或聊天记录。

### 为专题工作留一个可交接出口

党员发展、班团组织、成绩与学业帮扶、奖惩、活动、住宿和工作留痕都有独立入口。完成一个阶段性任务后，建立恢复点并导出备份；交接时给接收方一次恢复验证，而不是只传一个安装包或压缩包。
