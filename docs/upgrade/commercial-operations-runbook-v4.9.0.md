# v4.9.0 商业服务运维手册

本文是部署和售后操作边界，不包含真实密钥。正式配置应由受控部署人员通过密钥管理系统完成。

## 启动前

1. 创建独立 PostgreSQL 数据库，启用磁盘加密、最小权限账号、备份和恢复演练。
2. 在 KMS/HSM 创建 Ed25519 签名密钥，配置 `kid` 和只读公钥；私钥不可导出到仓库或普通环境文件。
3. 设置 `CWB_LICENSE_ENV=production`、`CWB_LICENSE_DATABASE_URL`、`CWB_LICENSE_DATABASE_SSL=true`、精确的 `CWB_LICENSE_CORS_ORIGINS`、`CWB_ORDER_ACCESS_SECRET` 和外置 `CWB_LICENSE_SIGNER_MODULE`；迁移完成后用 `admin:key` 创建数据库哈希管理员 Key。生产禁止配置 `CWB_LICENSE_ADMIN_TOKEN`，启动器会在发现共享明文管理员令牌、空 CORS 或关闭 TLS/HTTPS 时拒绝启动。
4. 在 `cwb_products` 配置正式价格、币种、主版本和产品状态；价格为零时生产服务拒绝创建订单。
5. 配置 HTTPS 反向代理、来源限制、日志脱敏、限流、告警和数据库连接池。
6. 如启用邮件，配置独立 mailer 模块。邮件发送先进入 `cwb_email_outbox`，失败只能重试，不得绕过订单状态。
7. 如启用试用、批量、学校授权或匿名指标，先配置受控管理员角色、售后记录和 `CWB_TELEMETRY_SALT`；不需要匿名指标时不要配置盐值。
8. 如启用前瞻/贡献者固定兑换码，使用 `pnpm --dir services/license-server redemption:generate` 在受控终端生成两段明文并立即存入密码管理器；部署模块只接收哈希，配置 `CWB_LICENSE_REDEMPTION_MODULE`，禁止把明文码写入 Git、环境文件、日志或网盘。

## 日常操作

- 手动订单：管理员创建订单并核对客户邮箱、档位和金额，再通过受保护的确认接口发码。
- 自动订单：支付平台 webhook 必须验证签名、时间戳和事件 ID；重放事件只返回幂等结果。
- 换机：先在设备页撤销旧设备，再让客户在新设备在线激活；不能复制本地许可证状态文件代替激活。
- 退款：先完成支付平台退款，再由验签 webhook 撤销许可证；不删除订单、审计或客户业务数据。
- 邮件：定时任务读取 outbox，成功标记 `sent`，失败记录有限错误摘要和下一次重试时间。
- 更新：包签名、SHA-256、清单签名和平台签名全部完成后，管理员才发布清单。
- 试用：通过 `/api/v1/admin/trials` 生成 1 至 30 天试用；核对邮箱、档位、到期时间和同意范围，不能手工修改已签发 token。
- 批量采购：通过 `/api/v1/admin/license-batches` 生成独立许可证清单；只通过受控交付通道分发，记录批次与售后负责人，不把 token 放进普通工单或群聊。
- 学校授权：先创建组织，再为每个工作区分配独立许可证；组织/工作区状态变化只影响授权元数据，不触碰客户本地学生数据。
- 匿名指标：只检查聚合趋势和错误率，不用于教学评价或学生画像；收到疑似业务字段时立即拒绝并检查客户端版本。
- 固定兑换码：`pilot-standard-perpetual` 对应普通永久更新版，`contributor-ai-perpetual` 对应永久 AI 增强版。用户输入码后服务端为工作区签发独立许可证；同一工作区幂等复用，不同工作区各自绑定独立设备上限。活动暂停只阻止新兑换，不自动撤销已签发许可证。

## 事故处理

- KMS 不可用：停止签发新许可证，保留已有客户的刷新宽限，不生成替代私钥。
- 数据库异常：停止写入订单/设备，先做健康检查和恢复；不得用内存状态覆盖数据库。
- 签名密钥疑似泄露：立即吊销当前 `kid`，生成新密钥并发布公钥轮换清单；保留审计证据。
- 支付 webhook 异常：暂停自动发码，保留事件原文哈希和事件 ID，人工核对后再重试。
- 邮件服务异常：订单仍可在受保护订单页交付；outbox 保留待发送状态，不在日志打印激活码。
- 匿名指标配置错误：删除或轮换指标盐值前先停止接收，不能把原始安装标识补写回数据库；指标不影响许可证刷新、学生数据和更新回滚。

## 不能从代码测试推出的证据

自动化契约测试不能证明真实 KMS、支付平台、邮件、证书、公证、DNS、CDN、数据库恢复或客户售后已经可用。每次正式发布必须记录环境、时间、版本、产物、签名、公证、安装升级和回滚结果。
