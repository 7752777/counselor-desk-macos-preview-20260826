## 发布顺序

完整测试 → 生成候选产物 → 真实平台安装/升级/恢复 → 产物签名与公证 → 生成 SHA-256 和签名清单 → 创建 Draft Release → 校验全部附件 → 公开 Release → 交付客户更新地址。任一步缺少证据都停留在 Draft，不移动 `v4.8.5` Tag/Release。

## 当前不能对客户承诺

当前工作区不能承诺支付后自动发码、云端实时同步、不可破解 DRM、签名安装包、macOS 公证、后台静默更新或生产授权服务已可用。AI 模型费用始终不包含在产品买断价内。
