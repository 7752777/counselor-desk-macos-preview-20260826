- 统一导出支持 CSV、XLSX、可打印 HTML、DOCX 和浏览器/ Electron PDF 路径；模板中心记录字段说明、敏感标记和导入规则。
- 实用工具支持本地抽签、分组、轮值、日期计算和名单清理，随机结果不由 AI 决定。

### 美观性与交互性

- 桌面端形成“左侧导航 | 中央主工作区 | 可折叠右侧上下文”的工作台结构；窄桌面收起右侧区，移动端退化为抽屉、单列和底部快捷栏。
- 首页以统计摘要、今日待办、紧急事项和当前上下文为主，避免把所有待办铺成长页面。
- 页面统一标题、统计条、筛选区、主操作、结果区的顺序；按钮保留明确层级，成功提示等待真实保存，失败保留输入并提供重试。
- 导航支持分组折叠、搜索、全部展开、恢复导航、常用项排序和移动端抽屉无障碍状态。
- 学生卡片修复了多余表格滚动代理；网页、离线构建和候选 Electron 页面均保留统一卡片展示目标。
- 本地浏览器已验收 `1440×920`、`1280×800`、`1024×768`、`390×844` 和 `360×800`：三栏、抽屉、遮罩、Escape、焦点返回、sticky 顶栏、无横向滚动和卡片模式均通过。

### 稳定性与数据安全

- 浏览器业务数据使用 IndexedDB，Electron 使用 SQLite 和独立附件仓；照片、证书、活动图片和业务附件只以附件 ID 关联。
- 附件写入有容量检查、70%/85%/95%风险提示、哈希去重、失败回滚和孤儿附件清理。
- v8 工作区协议保持 `schema_version: 8`；v4.6/v4.7/v4.8 业务数据版本按 v9/v10/v11 增量迁移，原则是只增不删。
- Electron v4.8.0 增加仓储健康检查、诊断错误码、版本化密钥、恢复口令、数据目录迁移和候选仓回滚。
- 自动备份支持桌面运行期间按时间/变更阈值检查，并记录最小化的 `v4_backup_runs`；浏览器关闭期间不能后台写文件，界面必须明确说明。
- 重点学生 PIN 锁已明确为“仅防误看，不是数据库加密”；不能把它当作数据库级保密方案。
- AI 建议、草稿、来源、授权、审计和业务确认采用快照/回滚边界；失败不显示虚假成功，重试不会重复制造事实记录。

### AI 赋能

- AI 已从独立工作台延伸到学生摘要、谈话 briefing、通知识别、任务拆解、成绩/预警辅助、就业/竞赛、证书草稿、心理语音转写、工作总结、班级分析、资料来源和工作留痕。
- 上下文支持当前学生、班级、事项、日期范围、科研课题、住宿批次、课表和本地来源；本地关联统一使用 `student_id`，不把内部 ID 发送给模型。
- 默认出站脱敏姓名、学号、电话、心理、纪律、资助等敏感字段；敏感字段授权只对当前请求生效，并写入授权审计。
- 来源记录保存 URL/标题/时间/引用片段和核验状态；来源变化或失效时，建议进入“需要复核”，不能继续当作权威事实。
- AI 结果只生成建议、解释、草稿或映射，必须人工确认；不得自动修改心理、危机、纪律、资助、预警、奖惩、住宿或审批事实。
- 通知本地预览会先保存来源和审计，再返回页面结果；本轮真实浏览器已验证该链路不再因旧 IndexedDB 集合缺失而失败。

### 互通性

- 浏览器、单文件离线 HTML、Electron SQLite、加密备份、恢复、手机交换包和局域网主机共用集合 manifest 与 `student_id` 关联规则。
- v4.8.0 局域网主机由 Electron 提供 SQLite、加密附件、HTTPS、一次性配对、二维码载荷、设备暂停/恢复/撤销、离线队列、幂等和字段级冲突收件箱。
- 附件传输支持分块、哈希、断点续传和授权下载；附件二进制不进入业务记录和普通 AI 出站。
- 学校内容推送只共享本地政策、资料和通知，不默认共享跨部门学生明细；角色是本地策略标签，不等于账号认证。

- 浏览器关闭期间无法后台写入用户选择的文件目录，也无法承担持续同步；浏览器只保证本地快照和用户主动备份。
- 局域网首期只允许同一局域网；自动发现、自动信任证书和公网实时同步不在当前范围。
- 云端只允许上传端到端加密备份包，不做云端明文实时业务同步。
- 内容推送角色不是登录系统；跨部门学生明细共享需要另立账号、角色、字段授权和合规项目。

- 当前没有足够的真实学校脱敏样本来建立 AI 中文质量、事实准确率、图片识别率和教师满意度基线。

## 下一步执行路线

### 批次 A：发布后持续一致性

- 复核所有 IndexedDB 入口只使用统一物理版本和集合 manifest。
- 复核无 IndexedDB、离线 HTML、Electron 和 v8 工作区初始化时不会互相覆盖有效数据。
- 代码发生变化时只重跑受影响测试；形成新维护里程碑时再运行完整门禁，不重复运行未发生代码变化的历史命令。

### 批次 B：桌面与备份实机

- 准备脱敏恢复包和损坏样本，按“诊断 → 恢复点 → 恢复口令 → 完整性校验 → 激活 → 失败回滚”逐步验收。
- Windows/macOS 分别验证安装目录和工作区目录可分离、可迁移、可恢复；记录真实版本、系统、路径和退出码。

### 批次 C：局域网与附件互通

- 先做主机/客户端配对和撤销，再做断网队列和字段冲突，最后做附件分块和长期压力。
- 每个设备只通过 HTTPS API 访问主机，不共享 SQLite 文件；冲突必须进入人工收件箱。

### 批次 D：AI 质量与业务效率

- 建立脱敏通知、谈话、成绩、就业、政策和工作留痕样本集，分别评价引用完整性、敏感字段出站、建议可执行性和人工修改量。
- 将 AI 按钮继续放在业务上下文中，明确“生成草稿、查看来源、人工确认、转任务/留痕”的连续路径。

### 批次 E：发布后维护

- 当前维护版本以 `v4.8.5` Release 为基线；涉及代码、迁移或公共接口时创建更高维护版本，不移动 `v4.8.5` Tag。
- 把真实设备、服务商、安装升级和恢复演练结果持续回填发布文档；不把测试草稿当正式资产。
- 建立 v4.8.1 维护池：真实学校反馈、性能采样、AI 质量基线、安装升级遥测替代方案和跨端恢复演练。

- 统一浅蓝活跃态、状态颜色、字号、行高、按钮高度和约 8px 工具卡片圆角；减少层层嵌套卡片和背景噪声。
- 导航支持分组折叠、搜索、全部展开、恢复导航、常用排序、抽屉遮罩、Escape、焦点返回和 `aria-expanded/aria-hidden`。
- 学生台账表格、卡片、照片模式在网页、离线 HTML 和候选 Electron 中保持同一数据逻辑；移动端表格模式有备用卡片，避免内容被全局移动 CSS 隐藏。

#### 稳定性与安全性

- 浏览器 IndexedDB、Electron SQLite、独立附件仓、离线 HTML、备份、恢复、交换包和手机工作包保持只增不删迁移；物理 IndexedDB v5 已升级到 v6，旧工作区会补建新集合而不删除旧数据。
- 照片、证书、活动图片、查寝材料和业务附件只保存附件 ID；容量阈值、哈希去重、失败回滚、孤儿附件清理和敏感导出确认已接入。
- Electron v4.8.0 具备诊断错误码、版本化密钥、恢复口令、健康检查、程序目录/数据目录分离和迁移失败回滚；重点学生 PIN 明确只是防误看，不是数据库加密。
- 大批量工作区替换保留历史和版本连续性；本轮移除重复深拷贝后，5,000 条替换仍以 `200ms` 为硬阈值并通过。
- 自动备份支持桌面运行期间按时间/变更阈值检查；浏览器关闭期间不能后台写文件，界面必须明确这一限制。

#### AI 赋能

- AI 已嵌入学生摘要、谈话 briefing、通知识别、任务拆解、成绩/预警解释、就业/竞赛、证书草稿、心理语音转写、班级分析、政策资料和工作留痕。
- 当前上下文可组合学生、班级、事项、日期、课表、住宿批次、科研课题和本地来源；内部 ID 不出站，默认姓名、学号、电话、心理、纪律、资助、照片等敏感字段脱敏。
- 敏感字段逐次授权并审计，来源保留 URL、标题、抓取时间、引用片段和核验状态；来源失效会标为需要复核。
- AI 输出只保存为建议、解释、映射或草稿，公共写入返回 `ready` 持久化承诺；失败会恢复内存快照，页面不会显示虚假成功。
- AI 不得自动修改学生事实、心理/危机、纪律、资助、预警、奖惩、住宿分配、班委等级或审批状态。

#### 互通性

- 浏览器、离线 HTML、Electron、手机交换包、加密备份和局域网主机共用集合 manifest、数据版本和 `student_id` 关联规则。
- v4.8.0 局域网使用主机事务、HTTPS、一次性配对码/二维码、证书指纹、设备暂停/恢复/撤销、离线队列、幂等键、字段级冲突收件箱和分块附件协议；客户端不直接共享 SQLite。
- 内容推送只共享本地政策、资料和通知，不默认共享学生明细；远程备份只上传加密包，不上传密钥和明文数据。

### 四、长期产品提升方向

- 功能上继续围绕“一次录入、多处复用”：任何谈话、家长联系、查寝、查课、活动、通知和任务都能在确认后回链到学生、班级、事项、工作留痕和统计，避免重复抄写。
- 美观上优先信息层级、密度和可读性，不用装饰性卡片堆叠替代工作流；所有高频页面保留明确的当前对象、下一步动作和结果反馈。
- 稳定性上把保存状态、备份新鲜度、同步状态、冲突数、附件状态和恢复点做成可见事实；任何失败都能保留输入、定位错误、重试或回滚。
- AI 上优先引用、脱敏、可解释和可撤销，不追求自动替人做决定；将模型质量纳入真实脱敏样本和人工复核数据，而不是只看接口返回成功。
- 互通上维持本地优先和协议稳定，逐步增加真实设备、真实服务商和真实附件的演练；不把云端、局域网或浏览器能力的假设混写成同一种可靠性。

### 五、发布判定
