# v4.9.0 版权与贡献者台账

商业发布前必须由版权方补齐并签署本台账。当前文件只提供维护模板，不把“仓库可提交”当作版权转让证据。

| 项目 | 需要记录的事实 | 状态 |
| --- | --- | --- |
| 产品源码 | 版权所有主体、首次创作时间、适用专有许可版本 | 待版权方确认 |
| 现有贡献 | 贡献者、提交范围、贡献日期、是否有书面授权 | 待逐项核对 |
| 外部素材 | 图片、图标、字体、模板、音频的来源和许可证 | 需随发布包复核 |
| 第三方依赖 | 包名、版本、许可证、版权声明和源码/notice 地址 | 见 `THIRD-PARTY-NOTICES.md` 与锁文件 |
| 商标与文案 | 产品名、图标、品牌素材的使用权 | 待版权方确认 |
| 商业服务 | KMS、支付、邮件、CDN 的账号归属和数据处理协议 | 部署前配置 |

在台账完成前，v4.9.0 只能作为受控候选，不应对外宣称已完成商业授权交付。
