## 可重复生成

前瞻版交付包由源码和受控构建产物组装，不把兑换码、许可证私钥或模型 Key 写入包内。重新构建前先生成网页端、PDF、Windows 安装包和 macOS Universal DMG/ZIP，再执行：

```powershell
pnpm build:forward-package -- output/学工智伴-v4.9.1-前瞻版交付包-YYYYMMDD
```

脚本会检查网页、Windows/macOS 安装包、三份 PDF 和脱敏样表是否齐全，扫描常见凭据格式，并在包根目录生成 `文件校验-SHA256.txt`。兑换码仍只通过维护者私下渠道发放。

## 前瞻版体验顺序

1. 第一次打开优先使用“前瞻版体验版”，依次查看今日概览、学生台账、导入预览、谈心谈话、工作留痕、成绩、住宿、备份恢复和 AI 工作台；“前瞻版授权体验”保留给需要单独核对授权流程的用户，两个文件都可以输入激活码。
2. 只用虚构或脱敏数据，不导入真实姓名、学号、电话、心理材料、密码、模型 API Key 或敏感附件。
3. 需要体验商业授权时，在“商业授权”或灰色 AI 按钮中输入维护者私下提供的兑换码；前瞻版网页和桌面安装包都已连接 `https://license.windsky.store`，不需要再换另一个网页文件。
4. 正式签名许可证支持本地签名校验激活；前瞻兑换码和友情 AI 码是服务端兑换凭据，必须联网核验，不能在完全断网时使用。桌面安装包会通过主进程联网，单文件 HTML 需要使用本轮包并保持网络可用。基础前瞻兑换码只兑换普通永久更新版；AI 前瞻兑换码直接覆盖为永久 AI 增强版。AI 许可证激活后仍可输入维护者私下提供的友情 AI 码，工作台会自动配置开发者托管 AI；重启后托管资格应保持。没有友情码时仍需体验者自行配置模型服务和模型 Key。
5. 反馈只提供页面名称、复现步骤、错误码、预期结果和脱敏截图。有效建议经核验采纳后，按前瞻体验计划规则赠送永久 AI 增强版。

## 授权服务器当前可验证事实

授权服务的健康接口和产品目录可以通过 HTTPS 访问；本轮公网复核时 `updates/latest?channel=preview` 与 `/downloads/v4.9.1/` 仍返回 `404`，因此更新清单、下载目录和三类活动码的公网生产验收不能写成已完成。服务端代码和本地契约覆盖了 `/api/v1/licenses/redeem`、`/api/v1/licenses/managed-relay/redeem`、AI 许可证激活、友情码兑换、托管 Relay assertion 和撤销清理，但真实明文码不在本工作区，本轮不回显。

兑换码明文只保存在维护者本机受控文件和私密渠道中，不进入 Git、客户端、测试压缩包、服务器环境文件、日志、普通备份或公开网盘。服务器部署侧只加载哈希配置；活动码泄露时可以暂停活动并单独处理已签发许可证。

- 授权服务健康接口和产品目录返回 `200`；本轮没有读取或回显三枚真实明文兑换码，其单枚实际可用性仍应由维护者在受控终端输入后核对。

## 当前限制

- Windows 测试安装包未使用正式代码签名证书，Windows 可能显示安全提示；这不代表安装包被篡改。
- 当前服务器仍是授权服务前瞻环境，签名器为部署侧 staging signer，不是正式 KMS/HSM。
- 支付、自动邮件交付、正式更新 CDN、Windows Authenticode、macOS Developer ID 签名和公证仍不能以前瞻版交付包作为已完成证据。
- 单文件 HTML 关闭后不能在后台自动更新文件；正式业务数据仍应使用工作台的备份和恢复功能。
- 如果激活窗口仍显示 `LICENSE_SERVICE_UNAVAILABLE`，先确认使用的是本轮新包、设备可以打开 `https://license.windsky.store/api/v1/health`，再重试；不要把兑换码当作正式许可证离线使用。
