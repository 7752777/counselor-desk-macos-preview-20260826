## 已落地能力

### 学生台账和导入

- 学生关联顺序为稳定 `student_id`、当前学号、历史学号，姓名不会自动合并。
- “学号、姓名、分数”可从学生名单增量导入入口更新已有学生；缺失字段默认保留，显式清空才清空。
- 导入预览显示新增、更新、冲突、重复、待人工核对和覆盖删除数量；失败可回滚。
- 学生档案保留照片、家长、紧急联系人、导师、班主任、居住和住宿等字段，扩展字段通过字段目录维护。

### 保存和批量操作

- 任务单条完成、恢复、顺延和批量完成等待真实保存；完成草稿与任务一起保存，失败恢复任务和草稿。
- 任务单条删除和批量删除使用统一事务路径，来源草稿变化与业务记录一起回滚。
- v4 业务批量删除先处理附件和来源草稿，再等待仓储保存；失败恢复记录、草稿和附件。
- v4 单条删除复用带附件的事务删除；成功提示只在保存 Promise 成功后显示。
- 文件批量删除改为整体事务：任一附件清理、仓储写入或草稿同步失败，全部文件条目和附件恢复。
- 用户输入失败时保留编辑窗口和重试入口，禁止显示“已保存”假成功提示。

### 样例体验

样例工作区包含 16 名学生，并覆盖任务、谈话、成绩、活动、工作留痕、住宿、查课、查寝、班委、家长联系、科研、量化考评、就业、竞赛、通讯录、课表、文件目录、模板和内容推送等页面。示例学生中保留“只有基础资料、成绩为空、期末可导入分数”的场景。

样例记录统一标记 `_demo:true`。不伪造 AI 审计、敏感授权、同步设备、离线队列或备份运行记录；文件目录示例不包含虚假二进制附件，真实附件必须通过上传流程进入附件仓。

### AI 和商业候选

- AI 入口统一经过授权守卫、业务层校验和请求前校验；未激活或未配置模型时不得出站。
- AI Key 与许可证分离，敏感字段需要逐次授权；结果只保存为建议、草稿或待确认记录。
- 文本 Responses 适配器和 relay 契约已通过固定脱敏测试；当前中转站的视觉和音频能力不能仅凭契约测试视为生产可用，需用户在撤销旧 Key 后用新 Key 实测。
- 商业候选包含四档产品、Ed25519 许可证、工作区绑定、设备上限、AI 权益、更新状态机和授权服务候选。许可证私钥不进入仓库。

## 仍未完成的正式商业条件

以下事项不能由当前源码或契约测试替代：

- 真实支付商户、支付平台签名 webhook、退款撤销、邮件交付和客户订单页生产验收。
- 生产 PostgreSQL 高可用、KMS/HSM 私钥托管、密钥轮换和事故演练。
- Windows Authenticode 签名、macOS Developer ID 签名与公证、真实安装升级和回滚。
- 下载 CDN、签名更新清单、客户分发域名和限速/监控。
- Windows/macOS 实机、真实手机局域网证书信任、断网队列、换机和附件恢复演练。
- 5,000 名学生、10,000 条业务记录及照片/证书/活动附件的真实端到端恢复证据。
- 当前外部 AI 中转站的视觉、音频、长上下文、额度和模型质量验收。

因此当前状态是“v4.9.0 商业候选”，不是“可直接面向客户正式发布的 v4.9.0”。在上述证据齐全前，不创建正式 Tag、Release 或客户下载链接。

## 安全和协作纪律

- 用户曾在聊天中暴露 API Key；该 Key 不属于本仓库测试凭据，必须在中转站撤销并重新生成。
- 不生成所有客户共用的万能商业 Key；固定内测兑换码只能由授权服务端兑换为独立许可证，并以哈希保存。
- 不将学生数据、附件明文、模型 Key、许可证私钥、设备令牌或订单令牌写入 Git、普通日志、业务备份或手机交换包。
- 仓库保持私有；私有仓库只降低源码暴露面，不能替代终端加密、备份、访问控制和授权服务安全。
