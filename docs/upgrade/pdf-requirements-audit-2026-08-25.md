## 3. UI 与交互逐项对照

### 已落地

- 桌面端采用固定左侧导航、中央主工作区和可折叠右侧上下文区。
- `>=1280px` 显示右侧上下文，`1024-1279px` 默认收起，`<=900px` 退化为导航抽屉、单列和底部快捷操作。
- 导航支持分组折叠、搜索、恢复、钉住常用项和自定义分类；自定义分类刷新后保留。
- 页面统一使用标题、统计摘要、筛选、主操作、结果区的顺序，表格与移动卡片保留同一业务动作。
- AI 页面支持平台 AI、自有 API Key 和高级自建服务三种配置方向；平台模式不要求用户填写共享模型密钥。
- AI 敏感用途以可读复选框呈现，敏感类别默认关闭，发送前逐次授权。
- AI 调用日志只保留用途、模型、状态、范围、来源数量、耗时和审计关联，可回到原业务页面。
- 失败和取消状态不会丢掉页面上下文；当前进程保留可重试文本，持久化 UI 状态不保存 Prompt、API Key 或完整响应。
- 任务支持开始日期、结束日期、截止日期、优先级、列表、时间轴和甘特视图；只有截止日期的任务显示为单日任务，日期倒置会按时间顺序展示。

### 部分落地或待外部验收

- 参考 PDF 的真实视觉页面尚未在本环境全部渲染为 PNG 对照。环境中没有 `pdftoppm`、`pdftocairo`、`mutool`、`gs` 或可用的 ImageMagick PDF 渲染器；本次完成了文字提取和源码/运行时检查，视觉像素级对照需要在有 Poppler 的环境补做。
- 平台 AI 的真实 Relay、学校域名、生产限流和第三方模型质量不由本地 JSDOM 测试证明。
- 真实手机摄像头二维码、移动麦克风、Windows/macOS 包签名、公证和局域网跨设备恢复仍需实机验收。

## 4. 统一通用兑换码边界

前瞻体验阶段允许配置两个长期活动兑换码：

1. 普通永久更新版：完整基础功能，不解锁 AI。
2. 永久 AI 增强版：解锁 AI 入口，但仍要求用户配置自己的模型 API Key，并自行承担模型服务费用。

同一个活动码可以给多位前瞻体验用户使用。服务端只保存活动码哈希，不把明文写入源码、客户端、日志、业务备份或 Git；首次兑换时按工作区签发独立 Ed25519 许可证，因此每个工作区仍有独立设备列表、刷新、撤销和审计。活动码泄露时可以暂停整个活动，已经签发的工作区许可证可以单独撤销。

这是一种前瞻体验权宜方案，不是不可破解的 DRM，也不适合替代正式购买许可证。活动码由 `services/license-server/scripts/generate-redemption-codes.cjs` 在受控终端生成，部署配置只接收哈希。
