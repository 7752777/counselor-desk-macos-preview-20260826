# 参考工作台功能与界面审计

更新时间：2026-08-19

本页记录用户提供的《图片笔记.pdf》九页参考界面所呈现的功能结构、交互习惯和视觉规律，并与辅导员工作台当前实现逐项对照。参考产品只作为体验研究来源，不复制其品牌、文案、图标、数据或实现。

## 版本边界

当前历史发布基线是 `v4.7.0`。本页记录的参考产品吸收批次已经完成当时的全量测试、构建、跨端验收、Tag、Release 和 Pages 部署；仓库私有化后原 Pages 当前不可用。历史版本之上的未发布 UI 收口候选另见[UI 收口与历史需求查漏补缺审计](./ui-redesign-closeout-audit-2026-08-19.md)，不能与本页的历史证据混用。

## 九页功能拆分

| --- | --- | --- | --- |
| 1 | 宿舍查寝 / 系统设置 | 楼栋房间、查寝任务、异常记录、统计卡、校历/教学周和首页卡片设置 | 在已有楼栋、房间、排宿、调宿基础上补齐查寝事实、异常处理、统计筛选；校历保留为后续配置项 |

| 3 | 工作台 / 工具箱 | 问候、KPI、今日课程、待办、风险图表和外部工具入口 | 首页摘要、今日任务、右侧上下文和本地 HTTPS 工具链接；不后台读取外部平台 |

| 5 | 通知 AI / 课堂点名 | 原文与结果双栏、文案风格、复制、重新生成、多班级点名和大屏模式 | 通知原文/结果双栏、草稿保存、转任务/留痕、点名结果复核；不自动确认事实 |

## 差距与交付状态

| 领域 | v4.6.0 基线 | v4.7.0 已发布结果 | 已知限制 |
| --- | --- | --- | --- |
| 查课 | 课表和考勤基础记录 | `v4_class_checks` 查课看板、状态、人数、异常和附件 | 课表自动排课仍需学校数据源或手工导入 |
| 点名 | 实用工具抽签 | `v4_roll_call_sessions` 多班级、不重复、种子复核、大屏准备 | 不替代正式教务点名，点名结果须人工复核 |
| 查寝 | 排宿、调宿 | `v4_dorm_inspections` 与 `v4_dorm_exceptions` 分离保存事实和处理状态 | 不替代学校住宿系统，检查规则由老师按校规填写 |
| 量化考评 | 班级分析和基础综测 | 规则、维度、积分明细、排名和导入 | 等级阈值只作为配置，最终评价由人工完成 |
| 工具箱 | 实用工具页 | `v4_tool_links` 分类、收藏、排序和 HTTPS 校验 | 外链标题和内容仍需使用者核验 |
| 就业防骗 | 就业资源目录 | `v4_employment_safety` 风险等级、理由、来源和核验日期 | 风险提示不是事实认定，不后台抓取或自动判断单位 |
| 竞赛 | 竞赛基础台账 | `v4_competition_resources`、`v4_competition_entries` 资源、报名、成员和附件 | 旧自由文本不会静默猜测学生身份 |
| 学业 | 成绩、预警、帮扶 | GPA、平均成绩、挂科、预警和学期聚合 | GPA 只在源数据提供 GPA/绩点时计算，不能由普通成绩强行推断学校口径 |
| 通知 AI | 通知解析和工作流 | 原文/结果双栏、主动粘贴或导入、草稿和转化 | 不读取钉钉、学校系统、剪贴板历史或浏览器通知 |
| 三栏体验 | 模块独立页面 | 桌面主区 + 可折叠上下文区；高频页面使用统计条、筛选区和结果区 | `<=900px` 退化为抽屉 + 单列，不强行压缩为三栏 |

## v10 数据与跨端边界

业务 `data_schema_version` 从 9 增量到 10；工作区协议 `schema_version: 8` 继续兼容。新增集合如下：

```text
v4_class_checks
v4_roll_call_sessions
v4_dorm_inspections
v4_dorm_exceptions
v4_assessment_rules
v4_assessment_entries
v4_tool_links
v4_employment_safety
v4_competition_resources
v4_competition_entries
```

这些集合由 `src/core/cwb-collections.js` 统一声明，并由 `src/core/v10-migration.js` 只增不删地初始化。浏览器 IndexedDB、单文件离线 HTML、Electron SQLite、备份恢复和手机交换包均从同一份清单派生，附件只保留附件 ID，不把二进制写入业务记录。

所有学生关系优先使用稳定 `student_id`。姓名、学号和班级只作为当前快照或兼容筛选；更正学号不能改变学生身份，也不能切断时间线、点名、竞赛和量化记录的关联。

## UI 规则

- 正文约 `14-15px`，行高 `1.6-1.7`；页面标题 `22-24px`，模块标题 `16-18px`，表格正文约 `13px`。
- 页面顺序固定为：标题与说明、统计摘要、筛选区、唯一主操作、结果区；导入、导出、模板和删除保持次级视觉层级。
- 主内容使用白色内容面、浅蓝选中态和蓝/绿/黄/红状态标签；页面分区不继续嵌套多层装饰卡片。
- `>=1280px` 显示左导航、中央主区和约 `300-340px` 的右侧上下文区；`1024-1279px` 右侧区默认收起并通过顶栏按钮打开；`<=900px` 使用导航抽屉、单列主区和底部快捷栏。
- 右侧区展示当前页面、待办/草稿、当前学生或事项的快速动作和 AI 授权提示；关闭/展开状态写入本机 UI 状态。
- 键盘可使用 Escape 关闭抽屉或弹窗；面板按钮使用 `aria-controls`、`aria-expanded`；开启 `prefers-reduced-motion` 时关闭非必要动画。
- 统计条和表格使用稳定尺寸，移动端不出现横向页面滚动；表格允许自身横向滚动以保持字段可读。

## AI 页面入口和边界

v4.7.0 将 AI 作为当前页面动作，而不是孤立聊天窗口：查课、查寝、点名、量化考评、就业防骗、竞赛、学业和通知页面都有就地入口。新增用途包括 `dorm_conflict`、`committee_evaluation_draft`、`research_checklist`、`class_summary` 和 `worklog_draft`。

AI 可以解释冲突、整理材料、生成清单和草稿；不得自动确认住宿床位、量化等级、奖惩事实、心理/危机/资助/纪律/预警结论、科研审批状态或学生事实。每次请求继续记录用途、模型、授权范围、来源和审计编号；敏感字段授权只对当前请求生效。

公开网页只允许用户明确提供并触发的 HTTPS 来源，保存 URL、标题、抓取时间、核验状态和引用片段；不做后台全网爬取。失效来源只能标记为“需要重新核验”，不能继续当作权威依据。

## 验证记录与限制

已完成的本地定向验证包括 `node --check`、`pnpm test:v47`、集合清单测试、AI 治理测试和发布脚本内联测试；完整 `pnpm test`、最终构建、目标视口真实验收、平台附件和公开 Release 证据已回填在 [v4.7.0 发布收尾记录](./release-v4.7.0.md)。

本轮不承诺数据库级加密、云同步、多人协作、学校教务系统自动接入、自动资格认定或自动分配宿舍。重点学生锁仍是防误看，不是加密；真实数据使用前仍应依赖受控设备、系统账户、磁盘加密和学校制度。
