## 生产配置边界

授权服务使用 [`.env.example`](../../services/license-server/.env.example) 作为变量目录样例。`bootstrap.cjs` 是生产启动器，只接受显式 `CWB_LICENSE_ENV=production`；本地内存契约应使用测试服务，不能把它当作生产后端。

生产启动会拒绝以下情况：PostgreSQL 未启用 TLS、CORS 为空或含非 HTTPS 来源、关闭 HTTPS、使用 `CWB_LICENSE_ADMIN_TOKEN` 共享明文管理员令牌、没有数据库哈希管理员 Key 查询能力。管理员 Key 通过受控命令一次生成、只显示一次，轮换时新增并撤销旧 Key。

生产服务只保存订单、许可证、设备、支付事件、邮件 outbox、更新清单和审计元数据，不接受学生事实、业务附件、模型 Key 或模型输入输出。许可证 token、设备凭据和模型 Key 不进入业务备份、手机交换包、普通日志或学生导出。

## 更新和授权的用户边界

- 普通版可以使用核心业务和当前主版本的安全修复，但 AI 入口保持锁定。
- 永久更新权益控制后续核心版本；AI 许可证控制 AI 功能；两者不是同一条件。
- 模型 API Key 和模型服务费用由客户承担，不包含在买断授权内。
- Electron 是正式商业授权载体；网页和单文件离线 HTML 只能提供受限伴侣能力，不能承诺抗逆向授权边界。
- 许可证丢失不影响学生业务数据恢复，但恢复业务数据后需要重新在线激活；更新失败时先保留旧数据目录、失败目录和恢复点，不卸载或手动删除。
